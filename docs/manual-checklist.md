# 사람이 직접 확인할 것

설계서 §7에서 옮긴 목록입니다. 자동 검사로는 확인할 수 없어 릴리스 전에 사람이 직접 확인합니다. 리팩토링(P0~P6d)이 끝난 뒤 한 번 확인하고, 그 뒤로는 큰 변경이 있을 때마다 다시 확인합니다.

확인할 때는 날짜, 기기, 브라우저와 결과를 아래 기록 표에 적어 주세요.

## 소리와 안전

- [ ] 실제 기타와 오디오 인터페이스의 1번 입력으로 연결했을 때 양쪽 귀에서 소리가 나는지 확인 (F1)
- [ ] 헤드폰으로 들을 때 프리셋끼리 음량이 비슷한지 확인 (S5)
- [ ] 피킹과 소리 사이의 지연이 어색하지 않은지 확인 (Q4, Q7)
- [ ] 연주 중에 인터페이스 USB를 뽑으면 바로 정지하고 한국어 안내 문구가 나오는지 확인 (Q7, U8)

## 휴대폰

- [ ] 아이폰 사파리와 안드로이드 크롬 실기기에서 연결, PANIC, 노브 +/−, 페달 순서 변경이 되는지 확인 (U1, U5)
- [ ] 휴대폰에서 끝까지 내려도 위쪽 막대의 연결과 PANIC 버튼이 보이는지 확인 (U1, P6c)
- [ ] 휴대폰에서 볼륨 페달을 한 번 탭하면 값이 바뀌지 않고, 끌어야만 바뀌는지 확인 (P6c)

## 오프라인

- [ ] 한 번 연 뒤 네트워크를 끊고 다시 열었을 때 앱이 실행되는지 확인 (M6)

## 이번 리팩토링에서 더해진 확인

- [ ] 마이크 권한을 거부했을 때 "주소창 왼쪽 자물쇠 아이콘" 안내가 나오는지 확인 (P6d)
- [ ] 다른 앱이 인터페이스를 쓰고 있을 때 "다른 앱이 장치를 쓰고 있는지" 안내가 나오는지 확인 (P6d)
- [ ] 프리셋을 저장하거나 내보냈을 때 화면 아래쪽 알림이 2초 동안 보였다가 사라지는지 확인 (P6d)
- [ ] 화면 읽기 프로그램(VoiceOver, TalkBack)으로 페달 켜기·끄기 버튼 이름이 한국어로 읽히는지 확인 (P6d)
- [ ] 예전 버전에서 저장한 사용자 프리셋이 새 버전에서도 그대로 보이는지 확인 (P4 저장 이전)
