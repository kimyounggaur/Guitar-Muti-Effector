## 화면

레이아웃의 P0 값은 11월 22일 `tests/e2e/baseline.json`에 기록한 초기 화면 측정값입니다. 현재 값은 같은 크기의 Chromium 창에서 프로덕션 빌드를 열어 측정했습니다. 페이지 길이 1.0은 브라우저 창의 높이 한 번에 해당합니다.

| 페이지 길이 | 1280 / 1440 / 1920px | 3.4 / 3.0 / 2.6화면 | 3.4 / 3.0 / 2.6화면 | 기존 데스크톱 배치 |

390px에서 연결과 PANIC을 담은 고정 막대는 54px입니다. 안전 안내와 장치 설정, 파일 연주는 각각 펼쳐서 쓸 수 있습니다. 데스크톱 초기 화면의 44px 미만 조작부는 464개이며, 설계서의 44px 기준은 휴대폰에 적용합니다.

튜너를 포함한 11개 페달 상세 패널을 각각 열어 확인했습니다. 390·1280·1440·1920px의 44개 패널 상태에서 실제 배경에 표시된 글자 1,336곳 중 명암비 4.5:1 미만은 0곳이었습니다. 320·390·600px에서는 같은 11개 패널의 33개 상태 모두 44px 미만 조작부와 가로 넘침이 0건이었습니다. GitHub 검사에서 1280px 노이즈 게이트 라벨의 글자 대비가 4.219:1로 측정돼 글자색을 검정으로 조정했습니다. 같은 배경색에서 계산한 대비는 4.94:1입니다.

11월 22일 보관 이미지와 다른 실행 환경 사이에는 글꼴 렌더링 차이가 있었습니다. 동일 환경에서 기존 빌드와 후속 빌드를 다시 비교하고, 의도한 휴대폰 배치와 상세 패널 명암 변경을 기준 이미지에 반영했습니다. 최종 Chromium 재검사에서 전체 화면 네 장과 1280px의 상세 패널 열한 장이 모두 기준과 픽셀 단위로 일치했습니다.
