# Guitar Multi-effector

브라우저에서 기타 입력이나 오디오 파일을 이펙트 체인으로 처리하는 웹 앱입니다.

## 실행 및 검사

Node.js 22 환경에서 `npm ci`, `npm run dev`를 실행합니다. 배포 전 `npm test`와 `npm run build`를 실행합니다. GitHub Pages는 `main`에 반영된 커밋을 빌드해 배포합니다.

## 안전한 시작

오디오 인터페이스와 헤드폰의 물리적 음량을 먼저 낮추고 입력 채널을 선택한 뒤 연결하세요. 긴급 음소거는 입력을 정지하고 마스터를 0으로 설정합니다. 출력 보호 회로는 청력이나 장비 보호를 보장하지 않으며 실제 장비의 음량 조절을 대신하지 않습니다.

마이크 사용과 AudioWorklet은 보안 컨텍스트(HTTPS 또는 localhost) 및 이를 지원하는 브라우저가 필요합니다. 모바일·오디오 인터페이스에 따라 입력 채널과 지연은 달라질 수 있습니다.

## 현재 검증 범위

자동 검사는 오디오 노드 모의 객체 및 워크릿 처리기를 이용합니다. 실제 악기와 인터페이스의 청감·왕복 지연 및 모바일 실기기는 별도 검증이 필요합니다. 4×12 캐비닛의 Dynamic 및 Mixed 마이크 설정에는 실제 녹음된 CC0 IR을 사용합니다. 나머지 캐비닛·마이크 설정과 리버브는 합성 임펄스를 사용합니다. 출처와 라이선스는 `public/irs/NOTICE.md`에 기록했습니다.
